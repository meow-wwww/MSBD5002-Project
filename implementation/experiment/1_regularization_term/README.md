This directory contains the code and result for Part I: the effect of the regularization term.

`run.py`: The main Python script to run the experiment.
`run.sh`: The shell script to run the Python script (under different experiment settings).

`log_2024.04.22-15.23.54.txt` and `result_2024.04.22-15.23.54.csv` are the test log and result file for this experiment.

`./result_analysis/__test.ipynb`: code for analyzing the result (result_2024.04.22-15.23.54.csv).
