This directory contains the code and result for Part II: baseline algorithm (SymANLS).

`run.py`: The main Python script to run the experiment.
`run_*.sh`: The shell scripts to run the Python script (under different experiment settings).

`log_2024.04.22-15.23.54.txt` and `result_2024.04.22-15.23.54.csv` are the test log and result file for this experiment.

`./result_analysis/result.ipynb`: code for analyzing the result.
